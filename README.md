# هیئت

میز کمیته برای بورس تهران و فرابورس. در تایم بازار پنج گروه را روی یک تابلو جمع می‌کند و فقط سهمی را در فهرست خرید یا فروش می‌گذارد که همان لحظه قابل اجرا باشد.

این برنامه توصیهٔ رسمی سرمایه‌گذاری نیست و سودی را تضمین نمی‌کند. صف و سرانه در چند ثانیه عوض می‌شوند.

## میزها

- **تکنیکال:** RSI، مکدی، استوکاستیک، بولینگر، میانگین‌های نمایی ۹ و ۲۱، میانگین ساده ۲۰ و ۵۰ و ۲۰۰، ADX، ATR، CCI، MFI، شیب OBV، ویلیامز، بازده ۳ و ۵ و ۷ روزه، جایگاه نسبت به ابر ایچیموکو.
- **بنیادی لحظه‌ای:** P/E نسبت به میانهٔ صنعت، EPS، P/S، P/B وقتی در خوراک باشد، شناوری. این میز صورت‌های مالی کدال را جایگزین نمی‌کند.
- **تابلو:** فاصله تا آستانه، حجم نسبت به حجم مبنا، سرانهٔ خرید و فروش حقیقی، قدرت خریدار، خالص پول حقیقی و حقوقی امروز، و تشخیص صف.
- **بازیگران:** خالص خرید حقوقی در پنجرهٔ ۳، ۵ و ۷ جلسه. این عدد مجموع حقوقی‌هاست، نه نام یک شخص. جمع‌کردن در ضعف قیمت و توزیع بعد از رشد جدا دیده می‌شود.
- **اخبار:** تیتر کدال و پیام ناظر با واژه‌های سود، قرارداد، زیان، توقف و تعدیل. اگر خبری نباشد این میز امتیاز را جابه‌جا نمی‌کند.
- **دبیر:** خریدِ چسبیده به سقف یا گرفتار صف سنگین را از فهرست خرید خط می‌زند. اگر سهم مثبت و داغ است ولی هنوز فروشنده دارد، در فهرست «مستعد صف» می‌آید، نه در خرید فوری. خرید در منفی فقط وقتی می‌آید که صف فروش قفل نباشد و حقوقی هنوز جمع کند.

## فهرست‌هایی که در تایم بازار دیده می‌شود

| فهرست | معنی |
| --- | --- |
| خرید قابل اجرا | امتیاز کمیته بالاست، قیمت حداکثر حدود یک درصد مثبت است و در سرخط فروشنده هست |
| خرید در منفی | قیمت منفی است، نمودار نشکسته، و جریان چندروزهٔ حقوقی هنوز خریدار است |
| مستعد صف، هنوز قفل نشده | تابلو داغ است ولی سقف دامنه پر نشده |
| فروش قابل اجرا | مومنتوم و جریان پول ضعیف شده و هنوز خریدار برای خروج هست |
| خروج بازیگر | بعد از رشد چندروزه، خالص حقوقی منفی است |
| حذف از خرید: صف خرید | حتی با امتیاز بالا، خرید اجرا نمی‌شود |
| حذف از فروش فوری: صف فروش | فروش تازه در این صف گیر می‌کند |
| متوقف یا ممنوع | تا رفع توقف سفارشی اجرا نمی‌شود |

روی هر کارت رأی هر پنج میز، سرانه به میلیون تومان، خالص حقوقی سه‌پنجره، و دلیل قابلیت اجرا نوشته می‌شود.

## اجرا

```bash
pip install -r requirements.txt
python -m heyat
```

میز روی [http://127.0.0.1:8080](http://127.0.0.1:8080) باز می‌شود و در ساعات بازار حدود هر ۲۰ ثانیه نو می‌شود. جلسهٔ پیش‌فرض شنبه تا چهارشنبه، ۹ تا ۱۲:۳۰ به وقت تهران است.

خوراک به این ترتیب انتخاب می‌شود:

1. `cdn.tsetmc.com` اگر از همان شبکه در دسترس باشد (معمولاً داخل ایران).
2. اگر متغیر `BRSAPI_KEY` ست شده باشد، [BrsApi](https://brsapi.ir/).
3. در غیر این صورت یک تابلو آموزشی با نمادهای ساختگی، تا منطق کمیته دیده شود. این فهرست بازار واقعی نیست.

```bash
export BRSAPI_KEY="کلید خودتان"
export HEYAT_PROVIDER=auto   # یا tsetmc یا brsapi یا fixture
python -m heyat
```

نرم‌افزارهای موجود هر کدام یک تکه را خوب نشان می‌دهند: دیده‌بان تی‌اس‌ئی‌ام‌سی و کارگزاری‌ها تابلو را، ره‌آورد نمودار و نسبت‌ها را، کدال افشا را. هیئت لایهٔ جمع‌بندی است و داده را از همان منابع عمومی می‌خواند.
