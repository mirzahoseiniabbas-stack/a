# تالار

نرم‌افزار آزمایشی معاملات بورس تهران و فرابورس. قیمت‌ها از دادهٔ عمومی بازار خوانده می‌شود و سفارش‌ها فقط در یک حساب مجازی ثبت می‌شوند. هیچ سفارشی به هستهٔ معاملات یا کارگزاری فرستاده نمی‌شود.

## امکانات

- شاخص کل، شاخص کل هم‌وزن و شاخص کل فرابورس
- دیده‌بان نمادها با جستجو، نقشه بازار و فهرست بیشترین ارزش، رشد و افت
- نمودار شمعی روزانه و حجم
- سفارش محدود و بازار، خرید و فروش، با کارمزد متعارف سهام
- پورتفوی، سفارش‌های باز و تاریخچه معاملات
- نمایش مبالغ به ریال یا تومان؛ ثبت سفارش همیشه بر پایهٔ ریال تابلو است

ساعت بازار، شنبه تا چهارشنبه از ۹ تا ۱۲:۳۰ به وقت تهران در نظر گرفته شده است. تعطیلات رسمی جداگانه اعمال نمی‌شود.

## اجرا

```bash
npm install
npm run dev
```

رابط روی `http://127.0.0.1:5173` بالا می‌آید. موجودی اولیهٔ حساب آزمایشی ۵ میلیارد ریال است و در `data/account.json` ذخیره می‌شود.

برای ساخت نسخهٔ واحد:

```bash
npm run build
npm start
```

اگر اتصال به دادهٔ زنده قطع باشد، آخرین نمای ذخیره‌شده در `server/snapshot.json` نشان داده می‌شود. به‌روزرسانی آن نما:

```bash
npm run snapshot
```

## کارمزد

نرخ پیش‌فرض سهام در `server/fees.mjs` است: خرید ۰٫۳۷۱۲٪ و فروش ۰٫۸۸٪. این نرخ برای تمرین است و ممکن است با کارمزد دقیق هر ورقه، از جمله صندوق‌ها، یکی نباشد.
